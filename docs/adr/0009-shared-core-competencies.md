# Shared core competencies

The shared competency core is problem-solving, technical/domain depth, communication, structure, and evidence/verification. Type-specific dimensions — code quality, collaboration, ownership/impact, and any future specialist dimensions — are scored only in interview types whose interaction produces that evidence. A dimension is never scored from absence of evidence.

**Status:** accepted — competency core and weights. Definitions and per-competency evidence thresholds remain open.

## Consequences

- Every type maps its questions and rubric to the same five core competencies.
- Coding can add code quality; behavioral can add collaboration and ownership; resume/project can add ownership/impact.
- A missing type-specific dimension is reported as "not assessed", not as zero.
- Competency definitions must be written precisely enough to prevent the same behavior being scored under multiple dimensions.
- Report and progress views must distinguish core competency scores from type-specific dimensions.
