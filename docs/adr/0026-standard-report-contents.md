# Standard shared-report contents

The shared formal report includes interview type, target role, date, duration, question/difficulty coverage, competency scores with evidence and confidence, an evidence-grounded narrative summary, limitations, integrity metadata (pauses, disconnects, hint count, hidden-test result), candidate annotations/disputes, and share status/expiry. It excludes raw transcript, audio, and any role-fit verdict or ranking.

**Status:** accepted — report field set. Evidence excerpts, confidence bands and integrity fields are accepted; display details remain open.

## Consequences

- The report schema separates candidate-visible, consumer-visible and internal fields.
- Raw transcript and audio are not part of the shared report by default.
- Integrity metadata must be factual and non-accusatory: pauses, disconnects, hints and hidden-test outcomes, not inferred intent.
- Candidate annotations/disputes appear alongside the affected competency, not as a separate hidden log.
- Share status and expiry are visible to both candidate and consumer.
- No role-fit verdict, ranking or recommendation is generated in the first tier.
