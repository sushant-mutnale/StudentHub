# Independent evidence means a distinct demonstration, not a paraphrase

An independent instance is a distinct demonstration in response to a different question or a substantive follow-up. Repeating the same claim within one answer does not count.

**Status:** accepted — evidence independence. Per-competency minimums remain open.

## Consequences

- The evaluator must link each instance to a distinct question/follow-up and a distinct demonstration.
- Elaboration within one answer is one instance, not two.
- The blueprint must create enough distinct opportunities to reach two instances per core competency.
- Follow-up depth contributes to independence only when it asks for a new demonstration.
- Confidence cannot be raised by restating the same evidence in different words.
- Evidence records must distinguish source turn, question intent and demonstration.
