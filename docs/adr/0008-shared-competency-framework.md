# Evaluation uses a shared competency framework with type-specific weights

Every interview type scores a common competency set, but each type weights those competencies differently and requires different evidence. Competency-level scores are comparable only within the same framework/rubric version; overall scores remain type-specific and are never compared directly across types.

**Status:** accepted — competency framework. Core competencies and weights are accepted; definitions and per-competency evidence rules remain open.

## Consequences

- A versioned competency taxonomy and rubric schema are required before evaluation can be implemented.
- Cross-session progress uses competency trends and type context, not a single overall score.
- A shared report must show which type produced each score and which rubric version was used.
- Type-specific evidence rules are mandatory: a behavioral claim cannot satisfy a coding-evidence requirement.
- Changing weights or definitions requires a new rubric version; historical scores are not silently recomputed.
