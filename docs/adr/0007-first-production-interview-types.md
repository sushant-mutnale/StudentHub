# First production interview types

The first production milestone covers behavioral/HR, technical knowledge, resume/project deep-dive, and DSA/coding interviews, in text and voice, with secure code execution for coding. System design, debugging/code review, case-based, and company/job-specific interviews are fully specified in the design but are not first-milestone production commitments.

**Status:** accepted — production sequencing. Deferred types remain in scope for the specification.

## Consequences

- Four blueprints and rubrics must be production-grade; the other four must not be designed out.
- Voice and coding are first-class production capabilities, not experiments.
- Context and evaluation contracts must be type-extensible so later types do not require a second engine.
- Deferred types may still be exposed as limited previews, but not marketed as production-ready.
- Recruiter/ATS consumption is not part of this milestone.
