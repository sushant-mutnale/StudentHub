# Formal audio recording is opt-in; declining means transcript-only

Formal audio recording is a separate opt-in. Declining does not make the candidate ineligible; the assessment proceeds with the server transcript as the authoritative record.

**Status:** accepted — audio consent. Audio access rules and dispute use remain open.

## Consequences

- Audio consent is separate from formal-assessment consent and from memory consent.
- The server transcript is authoritative whether or not audio is recorded.
- Declining audio must not degrade scoring, latency, or report completeness.
- Recorded audio is used for dispute review and quality, not for hidden scoring signals.
- Audio access is audited; candidates can see who accessed it and when.
- Audio expires after 30 days regardless of report retention.
- The report must not imply audio exists when it does not.
