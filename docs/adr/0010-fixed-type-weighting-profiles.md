# Fixed, versioned type-emphasis weighting profiles

Each production interview type has a published weighting profile for the five core competencies. Practice and formal assessments of the same type use the same profile, and weights change only through a new rubric version. Role/JD-adjusted and candidate-adaptive weights are excluded from the first tier.

**Status:** accepted — weighting model and initial numeric weights. Per-competency evidence thresholds remain open.

## Consequences

- Four profiles must be authored, reviewed and versioned with the rubric.
- Cross-candidate comparability is valid only within the same type and rubric version.
- Personalization changes question selection and follow-ups, not the competency weights.
- Reports must show the profile and rubric version used.
- Historical reports are not recomputed when weights change; a new version applies going forward.
