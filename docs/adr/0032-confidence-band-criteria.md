# Confidence bands reflect evidence count, consistency and coverage

Low confidence applies to one instance or conflicting evidence; medium to two consistent instances at expected difficulty; high to multiple consistent instances across contexts and difficulty with no contradictions.

**Status:** accepted — confidence band criteria. Exact per-competency thresholds and limitation wording remain open.

## Amendment (canonical engine)

The first-tier blueprint declares two slots per competency with no substantive formal follow-up, so first-tier formal sessions record at most two instances and cap at `medium` confidence. `high` remains a reachable contract state: any blueprint that declares three or more opportunities per competency, and therefore records three independent instances, reaches it in formal mode without contradiction.

The "dimensions" term is read as distinct question contexts. A type whose competency maps to a single dimension still reaches `high` when three independent instances span three distinct questions; the dimension clause is not an extra gate that a single-dimension type can never satisfy.

Practice adaptivity is a deliberate exception to "at expected difficulty": an instance demonstrated at an adapted level still supports `medium`, because the blueprint's declared level is recorded alongside it and the report discloses the adapted level as a difficulty-context limitation. Formal mode never adapts, so its "expected difficulty" condition holds by construction.

## Consequences

- Confidence answers "how well did this session support this score?", not "how good is the candidate?".
- Contradictory evidence caps confidence at low, even when the instance count is high; it never yields medium or high.
- Difficulty context affects whether an instance is expected-level, not whether the candidate is penalized.
- In formal mode the blueprint fixes difficulty, so "across contexts and difficulty" is read as distinct questions and dimensions at the blueprint's expected difficulty. High confidence remains reachable in formal mode when there are no contradictions.
- The evaluator must record why a band was chosen; a band without reasons is invalid.
- No fixed distribution is imposed across competencies or candidates.
- Reports must not present a low-confidence score as if it were settled.
